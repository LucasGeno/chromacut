# Flat Icons Guide

Prompt templates for generating clean, geometric flat-style icons on green-screen backgrounds.

## Full Prompt Template

```
Generate {N} flat-style {category} icons on a solid bright green (#00FF00)
chroma-key background. Clean geometric shapes, solid fills, minimal
shading, bold outlines (2-3px). Modern flat design aesthetic.

{Context line — what these are for and the visual tone.}

Arrange in a {cols}x{rows} grid with at least 80px of solid green gap.
No frames, no borders, no drop shadows on the green background.

The {N} icons:
- **{Name}** ({description with specific fill colors and outline color})
- ...

Style: Clean, professional, immediately readable at {display size}px.
Consistent outline weight across all icons.

NO green (#00FF00) in any artwork. Labels on a black strip below each row.
Row 1: LABEL1, LABEL2, ...
```

## Example: 4 UI Action Icons

```
Generate 4 flat-style UI action icons on a solid bright green (#00FF00)
chroma-key background. Clean geometric shapes, solid fills, minimal
shading, bold outlines (2-3px dark charcoal #333333).

These are action buttons for a web application toolbar.

Arrange in a 4x1 grid with at least 80px of solid green gap.
No frames, no borders, no drop shadows on the green background.

The 4 icons:
- **Upload** (upward arrow emerging from a tray, slate blue #4A6FA5
  fill with charcoal outline)
- **Download** (downward arrow into a tray, warm amber #D4943A fill
  with charcoal outline)
- **Delete** (trash can with lid slightly open, muted red #C45B5B fill
  with charcoal outline)
- **Settings** (single gear, cool gray #7A8A9A fill with charcoal
  outline and darker gray teeth)

Style: Clean, professional, immediately readable at 24px.
Consistent 2px outline weight across all icons.

NO green (#00FF00) in any artwork. Labels on a black strip below:
UPLOAD, DOWNLOAD, DELETE, SETTINGS
```

## Flat Icon Style Tips

- **Bold outlines** are key — they make icons readable at small sizes
- Use **2-3 consistent fill colors** across a set for cohesion
- Request "no gradients" if the generator adds unwanted shading
- **Geometric shapes** over organic curves — circles, rounded rectangles, triangles
- Keep **negative space** generous — flat icons should breathe
- Specify the exact outline color and weight for consistency

## When to Use Flat vs Pixel Art

| Use flat icons when... | Use pixel art when... |
|----------------------|---------------------|
| Modern/professional UI | Retro/playful aesthetic |
| Small display size (16-32px) | Medium display (48-128px) |
| Dense toolbars/nav | Feature illustrations |
| Needs to match system UI | Standalone branded assets |
